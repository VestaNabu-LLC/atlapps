Email support@vestanabu.com. We answer within two business days.

Before you write

  • Ledgerstone needs a Jira site administrator to open it: Jira settings → Apps → Ledgerstone.
  • The first audit runs right after install. If a section shows "unknown", use Run snapshot now on the Overview.
  • Ledgerstone only reads Jira. It never changes permissions, schemes, groups or users.

Please include your Jira site address and, if possible, a screenshot. Never send passwords or API tokens.
